## Documentation

Les projets sont documentés dans un site HTML : [`docs/index.html`](docs/index.html).

Pour la voir en local, il suffit d'ouvrir `docs/index.html` dans un navigateur. Pour voir aussi les projets intégrés dans les pages, mieux vaut servir le dossier avec un petit serveur, par exemple `php -S localhost:8000` à la racine, puis ouvrir `http://localhost:8000/docs/`.
